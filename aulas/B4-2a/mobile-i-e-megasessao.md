# B4 · 2ª SÉRIE · PROGRAMAÇÃO DE APLICATIVOS MOBILE I + MEGASSESSÃO — ITA NEGRO

- Componente II.18 (plano 612) · Função: Desenvolvimento de aplicativos mobile ·
  Classificação: Planejamento e execução · Carga: 80 h-a no bimestre (5 aulas/semana)
- Competências/habilidades do plano: 1.1 ambientes de desenvolvimento de software mobile ·
  1.2 construir interface gráfica para aplicativos mobile · 1.3 utilizar recursos de celulares
  e tablets
- Bases tecnológicas: dispositivos móveis e mercado; arquitetura; plataformas; cross-platform;
  desenvolvimento em blocos (sugestão do plano); ciclo de vida de app; layouts; texto, botões,
  imagens, listas, views; navegação de telas; recursos do dispositivo (galeria, imagens,
  contatos, acelerômetro, geolocation, giroscópio); serviços; notificações
- Papel no ITA NEGRO: APP v1 da casa (em blocos — App Inventor/PWA simples) consumindo os
  dados do back-end do B3. Fecha o MVP triplataforma: desktop v0.5 + web v0.8 + mobile v1.
- Formato aula-âmbar: 15 teoria + 30 prática + 5 retrospectiva.

## MEGASSESSÃO (marco da 2ª série — sem. 15)
Formato: feira interna (2h). Cada equipe demonstra o produto completo para banca de
professores (técnicos + BNCC). Critérios publicados na semana 1:
1. Funciona nas 3 plataformas com o mesmo banco (30%)
2. Segurança básica: sem SQL Injection, sessão e permissões corretas (25%)
3. Identidade e usabilidade conforme manual de marca (20%)
4. Trabalho em equipe evidenciado (commits de todos, papéis rotativos) (15%)
5. Pitch de 5 min dentro do tempo (10%)

## Avaliação (formato plano 612)
- Formativa: retrospectivas + QA cruzado (sem. 13) com relatório.
- Cumulativa: checkpoints (sem. 5, 7, 10) + marco app v1 (sem. 15).
- Somativa (curso): a MEGASSESSÃO fecha o ciclo da 2ª série com a banca interna.
- Autoavaliação: portfólio anual. Recuperação contínua: sem. 14.

## Entrega para a 3ª série
MVP triplataforma + banco v1.2 + requisitos v1.0 + código de conduta → matéria-prima do TCC.
Na 3ª série o produto é endurecido (segurança, framework, testes, sensores) e defendido em banca.
